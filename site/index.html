syshm

Run classic Mac OS on arbitrary hardware by replacing the bottom of the OS instead of emulating a whole Power Mac.

For macOS and Linux, on AArch64 (Apple silicon) and x86_64.

View on GitHub Get Started

How It Works

On a real Power Mac only the NanoKernel runs in supervisor mode. The 68k emulator, the Toolbox, applications and drivers all run in PowerPC user mode and reach the kernel through a small interface.

syshm runs all of that Apple code unmodified, as the guest, and supplies everything below the interface as an ordinary program on the host.

Where Mac OS looks to the machine for drivers, syshm puts its own in the device tree, as a Mac’s firmware would. They’re thin: the work is done on the host. The system helpers, optional extras on a disk of their own, work the same way: guest enhancements that make the screen follow the window, and a 3D engine.

Get Started

syshm doesn’t include any Apple software. You’ll need an image of a Mac OS CD from 8.5 to 9.0.4. syshm starts the “Mac OS ROM” file from the CD or the installed disk, as an iMac’s firmware does.

Or build it with make. SDL2 (window and sound) and libslirp (networking) are used if they’re installed. The JIT runs on AArch64, on Apple silicon Macs and Linux alike; x86_64 hosts interpret.

Install Mac OS

./syshm disk create hd.img 2G "Macintosh HD"
./syshm boot --disk hd.img --cdrom 85.iso --window --nvram syshm.nvram

In the installer’s Options, turn off “Update Apple Hard Disk Drivers”.

Start up

./syshm boot --disk hd.img --window --nvram syshm.nvram

Add --tools for a disk of guest tools: guest enhancements that make the screen follow the window, and the 3D engine. Add --share DIR to see a folder of yours as a disk in Mac OS. The README has the rest.
