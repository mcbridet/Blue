Welcome to

Blue

Run classic Mac OS on arbitrary hardware by replacing the bottom of the OS instead of emulating a whole Power Mac.

For macOS and Linux, on AArch64 (Apple silicon) and x86_64.

View on GitHub Get Started

How It Works

On a real Power Mac only the NanoKernel runs in supervisor mode. The 68k emulator, the Toolbox, applications and drivers all run in PowerPC user mode and reach the kernel through a small interface.

Blue runs all of that Apple code unmodified, as the guest, and supplies everything below the interface as an ordinary program on the host.

Where Mac OS looks to the machine for drivers, Blue puts its own in the device tree, as a Mac’s firmware would. They’re thin: the work is done on the host. The system helpers work the same way. Once the Finder is up, Blue offers to install them, then restarts Mac OS: guest enhancements that make the screen follow the window and share the clipboard, a 3D engine, OpenGL, and a library for Pippin titles.

Get Started

Blue doesn’t include any Apple software. You’ll need an image of a Mac OS CD from 8.5 to 9.2.2. Blue starts the “Mac OS ROM” file from the CD or the installed disk, as an iMac’s firmware does.

Or build it with make. SDL2 (window and sound) and libslirp (networking) are used if they’re installed. The JIT runs on AArch64 and on x86_64 processors with x86-64-v3 (Intel’s Haswell and AMD’s Excavator on), on macOS and Linux alike; older x86_64 processors interpret.

Install Mac OS

./blue disk create hd.img 2G "Macintosh HD"
./blue boot --disk hd.img --cdrom 85.iso --window --nvram blue.nvram

In the installer’s Options, turn off “Update Apple Hard Disk Drivers”. A 9.2.2 CD that restores an image with Apple Software Restore instead needs the new disk chosen as its destination.

Start up

./blue boot --disk hd.img --window --nvram blue.nvram

In the window, once the Finder is up, Blue offers to install its guest tools: guest enhancements that make the screen follow the window and share the clipboard, the 3D engine, and OpenGL. Add --cdrom-drive or --floppy-drive for an empty drive, and drop a CD or floppy image on the window to put it in; --share DIR shows a folder of yours as a disk in Mac OS. The README has the rest.

Thanks

Blue stands on other people’s careful work:

  • Elliot Nunn’s reverse engineering of the Power Mac ROM: NanoKernel, powermac-rom (NanoKernel 2, its tasks and Multiprocessing Services) and tbxi. Blue’s kernel is its own code, written to what these document.
  • QEMU and OpenBIOS, which run Apple’s own NanoKernel 2, for Blue’s to be checked against; and QEMU’s libslirp for networking.
  • SheepShaver and Basilisk II, which showed long ago that classic Mac OS can run on a host kernel.
  • Mesa and SGI’s OpenGL Utility library, for OpenGL.
  • SDL, Dear ImGui and Robin Casady’s ChicagoFLF, after Susan Kare’s Chicago, for the window.
  • Apple’s own documentation: Inside Macintosh, the technotes and developer notes, and Darwin’s headers.
